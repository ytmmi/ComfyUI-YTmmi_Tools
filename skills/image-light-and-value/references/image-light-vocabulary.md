# 光影词表：光位、光质、明度键（Light & Value Vocabulary）

`image-light-and-value` 的参考资料：可直接落笔的英文写法。
本文件只给**词与写法**，判断流程见 SKILL.md。

## 一、光位与光质

| 概念 | 英文写法 | 备注 |
| --- | --- | --- |
| 主光 | `the key light` | 一张图只有一个主光 |
| 补光 | `the fill` | 只允许改暗部 |
| 轮廓光 | `a rim of light along the far edge` | 主体与背景分离 |
| 实用光源 | `a sodium lamp above the doorway` | 画面里看得见的灯 |
| 逆光 | `backlit, the source behind the subject` | 正面压暗、边缘亮 |
| 顶光 | `a hard overhead light` | 眼窝与下颌出阴影 |
| 底光 | `light bouncing up from the wet pavement` | 罕见，制造不安 |
| 硬光 | `hard light, sharp-edged shadows` | 小光源 |
| 软光 | `soft light, long gentle transitions` | 大面积光源 |
| 漫射 | `diffused overcast light, shadows barely there` | 阴天 |
| 阴影边缘 | `a shadow edge that stays crisp` / `a shadow edge that dissolves` | 软硬的可观察证据 |
| 投影变形 | `the window grid stretched across the floor at an angle` | 投影要跟角度走 |

## 二、光的五个落点（写「物」，不写方位）

`it reaches the left cheek, the ridge of her nose and the collarbone`
——落在**能被看见的物体上**，比 `from the left` 有效。

衰减：`the light dies within an arm's reach` / `the light dies inside the frame`。

## 三、明度键

| 键 | 英文写法 | 画面 |
| --- | --- | --- |
| 低调 | `low key, most of the frame held in shadow` | 大面积暗，戏剧 |
| 中间调 | `mid key, the shadow and the highlight nearly equal` | 平实 |
| 高调 | `high key, a narrow band of shadow only` | 通透、干净 |
| 高反差 | `a wide value range, the shadows crushed` | 冲击 |
| 低反差 | `a narrow value range, everything mid-grey` | 静谧、日系 |

## 四、具名布光

`Rembrandt`（暗面颊上一个三角光斑）、`Butterfly`（鼻下蝶形小影）、
`Split`（半边脸全暗）、`Loop`（鼻侧小三角影）、`Rim / Edge`（边缘亮线）。

## 五、光比（stops）

```text
0 = 1:1        1 = 2:1       2 = 4:1
3 = 8:1        4 = 16:1      5 = 32:1      6 = 64:1
```

常用区间：柔和女性人像 `key to fill about two stops under`；
戏剧男性 `the fill sits three to four stops under the key`；
商业平光 `key and fill within half a stop`；
背景压低 `the background sits one to two stops under the key`；
画面内实用光源 `the practical sits about two and a half stops over the key`。

**一条硬约束**：画面里**不允许有比主光更亮的背景物**，
否则视线会被背景抢走（除非那个亮点就是你要的焦点）。

## 六、影与色

| 概念 | 英文写法 |
| --- | --- |
| 暗部偏色 | `the shadows lean cool teal` / `deep indigo` |
| 暗部不压死 | `detail still readable in the shadow` |
| 高光形状 | `a narrow specular streak along the rim` |
| 高光不过曝 | `the highlight stops one step short of blowing out` |
| 冷暖分区 | `warm on the near cheek, cool on the far side` |

## 七、常见空词与替换

| 空词 | 换成 |
| --- | --- |
| `cinematic lighting` | 光源 + 方向 + 质量 + 落点 |
| `dramatic lighting` | 光比（`three stops under`）+ 影子的方向 |
| `beautiful lighting` | 一句可观察的后果（`the pavement throws a long shadow to the right`） |
| `soft lighting` | 阴影边缘的描述 |
| `moody lighting` | 明度键 + 暗部色（`low key, shadows leaning blue`） |
| `god rays` | 一处能看见介质的光柱（`a shaft through the window gap, dust suspended in it`） |
