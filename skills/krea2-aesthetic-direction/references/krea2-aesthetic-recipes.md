# Krea 2 调性配方库

配套 `krea2-aesthetic-direction`。每条配方给出**结构骨架**（主方向 / 光 / 材质 / 色盘 / 质感），
使用时**只换内容，不改结构**；同一条配方连续用两次必须换至少三个内容槽位，否则会套路化。

骨架记法：`方向 ｜ 光 ｜ 材质 ｜ 色盘 ｜ 质感`

## 01 胶片写实 Filmic Realism
- 方向：35mm 或 120 中画幅的纪实摄影，不修饰
- 光：单一自然光源（侧窗 / 阴天漫射 / 黄昏侧逆），影子软且长
- 材质：皮肤有毛孔与油光、布料有纹理、金属暗哑
- 色盘：60% 低饱和中性（米 / 灰 / 褐），25% 环境色偏（冷青或暖黄），15% 主体色
- 质感：明显颗粒、轻微色差、边角轻微失焦
- 反面：锐利无噪点、HDR、四周打光

## 02 编辑大片 Editorial Fashion
- 方向：杂志内页 / 品牌 KV，构图敢留白
- 光：硬光 + 大面积阴影（`one hard key from 45° upper left`），或闪光灯直打
- 材质：高级面料（哑光羊毛、丝缎、漆皮）+ 干净背景
- 色盘：主色占 70%，一个**高饱和强调色**只用在配饰或背景一角
- 质感：几乎无颗粒，皮肤保留细微毛孔，不过度磨皮

## 03 静谧留白 Quiet Space
- 方向：侘寂 / 极简室内，近乎无人的空间
- 光：单侧窗光，光束里能看到尘
- 材质：纸、灰泥、木头、亚麻，全部哑光
- 色盘：90% 同族低饱和 + 一个深色锚点（门洞 / 阴影）
- 质感：极轻微颗粒，负空间占画面一半以上

## 04 奢华材质 Luxury Material
- 方向：产品 / 静物主视觉
- 光：大面积柔光箱 + 一块反光板，形成一条干净高光带
- 材质：2–3 种，且**互相衬托**（磨砂玻璃 vs 抛光金属 vs 粗石）
- 色盘：70% 底色、20% 次色、10% 金属或彩色强调
- 质感：干净但允许一处水渍 / 指纹 / 灰尘

## 05 粗野主义 Brutalist
- 方向：混凝土巨构、硬边几何
- 光：单一硬光形成**大面积黑白分割**，或阴天平光压掉层次
- 材质：清水混凝土、锈蚀钢、玻璃反光
- 色盘：灰阶为主 + 一个暖色人工光点
- 质感：轻微颗粒、边缘不完美

## 06 赛博霓虹 Neon Nocturne
- 方向：雨夜城市、霓虹反射
- 光：多光源但**各有色相**（钠橙 / 青蓝 / 品红），湿地面做镜面
- 材质：湿沥青、脏玻璃、贴纸、锈
- 色盘：20% 高饱和霓虹 + 80% 深蓝紫暗部（暗部必须有色）
- 质感：高光溢出、轻微色散、雨丝

## 07 手作纸感 Paper & Craft
- 方向：纸艺 / 拼贴 / 版画
- 光：均匀柔光，影子很浅（纸是平的）
- 材质：卡纸、撕边、胶痕、纸纤维
- 色盘：4–6 个平涂色，互相撞色但明度一致
- 质感：纸张纹理清晰、边缘有撕痕、可见接缝

## 08 复古广告 Vintage Ad
- 方向：60–70 年代印刷广告
- 光：平光，无立体感
- 材质：网点印刷、套色偏移、油墨不均
- 色盘：3 色套印（红 / 墨绿 / 米黄）+ 纸黄白
- 质感：网点、套印错位、折痕

## 09 暗调油画 Chiaroscuro
- 方向：明暗对照法，主体从黑里浮出
- 光：单一强侧光，背景全暗
- 材质：厚涂笔触、亚麻布纹、旧清漆黄
- 色盘：80% 深褐黑 + 15% 皮肤白 + 5% 朱红
- 质感：笔触可见、清漆裂纹、边缘柔化

## 10 日系清新 Airy Japanese
- 方向：日常记录、透明感
- 光：高调逆光 / 大面积白墙反光
- 材质：棉麻、木、玻璃杯、水
- 色盘：高明度低饱和（白 / 淡蓝 / 浅木色）+ 一个饱和点（红果子 / 黄伞）
- 质感：细颗粒、轻微过曝、柔和高光

## 11 工业纪实 Industrial Reportage
- 方向：厂房 / 基建 / 机械现场
- 光：头顶工业灯 + 灰尘散射（体积光）
- 材质：镀锌钢、油污、警示漆、混凝土
- 色盘：冷灰 + 安全橙 / 黄
- 质感：手持感、轻微抖动、灰尘颗粒

## 12 粉彩梦境 Pastel Dream
- 方向：超现实柔和场景
- 光：无方向柔光 + 轻微辉光
- 材质：绒面、云、糖霜、磨砂塑料
- 色盘：3 个粉彩同族 + 一个稍深色定住画面
- 质感：柔焦、轻微光晕、低对比

## 使用纪律

1. **配方锁结构不锁内容**：主体、道具、场景永远来自用户需求。
2. **一次只用一个主配方**；要混用时，用一个主配方 + 一个"偏移层"，
   并在正文里写明偏移加在哪一层（例如"色盘走 06，材质走 04"）。
3. **防套路化**：同会话连续两条不要用同一配方；复用时要换掉
   光位方向、材质组合、色盘占比中的至少两个。
4. **不要照搬示例道具**（例如 04 的"一片叶子"）——那是占位，不是内容。
