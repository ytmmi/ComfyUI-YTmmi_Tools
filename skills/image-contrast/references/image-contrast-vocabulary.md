# 对比词表：八个维度与可观察证据（Contrast Vocabulary）

`image-contrast` 的参考资料：每个维度怎么写、怎么读出画面对比。
本文件只给**词与写法**，判断流程见 SKILL.md。

## 八个维度（一次只选一到两个做主）

| 维度 | 英文写法 | 画面 |
| --- | --- | --- |
| 明暗 | `a wide value range from deep shadow to near-white` | 体积、戏剧 |
| 冷暖 | `warm light against a cool blue shadow` | 情绪、分离 |
| 互补 | `saturated orange against deep blue` | 冲击、张力 |
| 面积 | `the small bright mass against the large dark field` | 焦点 |
| 边缘 | `one crisp edge against a soft, dissolved background` | 清晰度 |
| 纹理 | `sharp only on the face, everything past the shoulder softening` | 质感 |
| 形状 | `a single unbroken silhouette against the background` | 剪影 |
| 密度 | `one crowded corner, the rest of the frame left empty` | 疏密 |

## 抑制项（写清什么被压下去）

| 压什么 | 英文写法 |
| --- | --- |
| 压背景细节 | `the background keeps a low contrast, almost textureless` |
| 压色彩 | `the walls hold a narrow, desaturated range` |
| 压锐度 | `the distance already softens` |
| 压高光 | `no highlight in the frame is brighter than the face` |
| 压空隙 | `the negative space is not evenly split` |

## 焦点：最高对比处

焦点不是最亮的地方，而是**对比最强的地方**。
一个画面里应该只有**一处**最高对比点；把它钉在主体上，视线自然先到那里。

```text
the face carries the only strong value contrast in the frame,
while the room behind stays low-contrast
```

## 常见的「看起来有对比其实没有」

- 颜色不同但明度一样（红与绿同明度 = 没有明暗对比）；
- 后景细节很多、亮度接近主体（杂）；
- 全图同一锐度（没有清晰度对比）；
- 两处高光同强度（焦点分裂）。

修法：先减掉一个对比维度，再保留一个主对比。
